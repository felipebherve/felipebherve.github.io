FALAVADO: a Mesa dos Pensadores

FALAVADO: the Thinkers' Table

Uma conversa simulada entre 20 pensadores (filósofos, cientistas e escritores), com o bufão Triboulet servindo a mesa: a pessoa escreve um pensamento e cada pensador responde a partir da própria obra. Site em português, inglês e espanhol com acessibilidade (letra para dislexia, modo para daltonismo e leitor de texto), exemplos narrados com as vozes Daniel e Maria e uma skill para usar dentro do Claude. Site estático no GitHub Pages, sem servidor: cada pessoa usa a própria conta de IA. Feito com Claude, de uso gratuito e venda proibida. Lançado ao público em 13 de outubro de 2026.

A simulated conversation among 20 thinkers (philosophers, scientists and writers), with the jester Triboulet serving the table: you write a thought and each thinker answers from their own work. The site is in Portuguese, English and Spanish, with accessibility built in (a dyslexia-friendly font, a colour-blind mode and a text reader), narrated examples with the Daniel and Maria voices, and a skill to use it inside Claude. A static site on GitHub Pages with no server: everyone uses their own AI account. Built with Claude, free to use and not for sale. Launched to the public on 13 October 2026.
